結論：3つの発見

① フジクラの2Q計画は「サンドバッグ」
通期4,320億−中間1,980億=下期2,340億。中間から1Q実績1,048億を引くと2Q計画は932億(1Q比-11.1%)。ところが2Q売上計画は+4.2%の増収=増収なのに減益という不自然な計画(想定OPM 22.2%、1Q比-3.9pt)。1Q確定後にこの数字を出しているので、売価が7-9月も維持されれば11月に3回目の上方修正が出る蓋然性が高い。8月修正分は織り込み済み・未織り込みは「11月の3回目」
② 「川上vs川下」の逆感応度は成立していなかった
三菱マテリアル(川上)とダイジェット(川下)は両方が同じ「在庫タイムラグ益」で同方向。川下も(a)値上げ転嫁が先に効き(b)原料原価は平均法で遅れて上がるため。ペアトレード不適、順張り時も分散になっていない。逆回転はダイジェット側が構造的に大きい
③ 2026年の下方修正の主犯は「円安」ではなく「中東情勢」
一次資料で「円安」を下方修正理由に明示していたのはシャープと日本電気硝子の2社のみ。カゴメ・住友ゴム・ハウス食品・一正蒲鉾は検証の結果円安逆風に該当せず(主因は中東情勢起因の原燃料・包材高、住友ゴムは為替がむしろプラス寄与)。報道の「円安コスト増」は要検証

フジクラ以外の「実力」トップ3

2位 三井金属(5706) — 非鉄製錬7社でAI/DCが一次ドライバーと明言される唯一。2月の3度目の修正も8/7の修正も主因はAIサーバー向け極薄電解銅箔(HVLP)。同日に420億円の増産投資を発表し2026年9月に月産840t、2030年度に当該事業利益倍増の計画まで提示(設備の裏付けあり)。ただし8/10に「上方修正も市場予想に届かず」で急反落=期待値は既に高くエントリー水準の見極めが必要

Ⅱ. 資源ペア：三菱マテリアル(5711)×ダイジェット(6138)

三菱マテリアル(5711) 8/6上方: 営業360→1,300億(+261.1%)、経常730→1,800億
価格前提の見直しが全て: APT(タングステン) 855→3,017$/MTU、銅500→579¢/lb、金4,000→4,129$/oz、ドル円150→158円
経常+1,070億の要因分解(会社開示): 価格差(販売価格)+1,666(うちタングステン製品+1,595) / 価格差(コスト他)△794(うちタングステン原料△848) / 為替差+107(うち在庫評価+50→純粋な円安寄与は+57億程度) / 数量差+30 / 受取配当金+68
外部要因タングステン正味+747億=営業増益940億の約79%。円安の直接寄与は営業段階で6〜11%にすぎない。この上方修正は円安相場ではなくタングステン相場である
感応度: ドル±1円→営業±4.7億 / 銅±10¢/lb→経常±16.4億 / タングステンの感応度は非開示(最大要因の感応度が出ていない)
逆回転: 会社自ら「タングステン価格高騰前の低価格在庫払出効果は第4四半期以降縮小を想定」と明記
ダイジェット工業(6138) 8/7上方: 営業4.0→11.0億(+175.0%)、配当35→70円
理由は①原料タングステン高騰に対する値上げの効果 ②超硬工具の需要好調 ③「高騰以前に購入した在庫も含め平均法にて払出単価を算定しているため、現時点では原価への影響は限定的で、利益増加の要因となっている」(開示原文)
外部要因川下なのに増益なのは「値上げ転嫁」+「平均法による低価格在庫の払出タイムラグ」の2本立て。②は三菱マテリアルと全く同じメカニズム
ペア判定: 逆相関ではない。同一ファクターへの二重エクスポージャー
想定していた「川上=原料高で儲かる/川下=原料高でコスト増」は成立していない。裏付けとして三菱マテリアル自身の超硬製品セグメント(川下)も経常129→185億で、内訳は数量+25/販売価格+10/コスト他△8と穏当=川下の増益は「需要+値上げ」が主。ダイジェットの+175%はそれに比べ在庫効果への依存が明らかに大きい。逆回転はダイジェット側が構造的に大きい(低価格在庫を払い出し切れば原料高がフルに原価へ乗る。三菱マテリアルはH.C.Starck等で川上を保有し販売価格上昇を取れるため剥落しても原資が残る)

Ⅲ. 円安逆風(コスト側)：報道の多くは誤り

シャープ(6753) 8/7下方: 営業490→300億(-38.8%)、売上17,700億は据え置き(=需要要因ではなく純粋にコスト要因)
想定為替156→160円。セグメント別: スマートライフ410→250億(-160億)/スマートワークプレイス+30億/ディスプレイデバイス-60→-120億(-60億)
1Q要因分解: 売価+143/経費+24/為替影響-87/コスト・モデルミックス-79/販売影響-72
典型的な内需販売×輸入部材型。白物家電は増収なのに利益が落ちる=転嫁不足。棚卸資産はメモリ先行調達で増加(2,891億)=含み損リスクも積み上がっている
株価は下方修正にもかかわらず対TOPIX+2.1pt(AIサーバー参入期待が相殺)
日本電気硝子(5214) 7/31下方: 営業330→200億(-39.4%)、経常330→250億(-24.2%)
理由分解: (a)ディスプレイの販売数量減(パネルメーカー稼働低下) (b)複合材の生産性改善の遅れ (c)原燃料価格等の上昇(為替影響を含む) (d)欧米拠点閉鎖費用。修正文言は「中東情勢及び円安の影響により原燃料価格等が高騰」
重要な非対称性: 営業段階では円安がコスト増だが、営業外では海外子会社借入の評価替えで為替差益+30億(前年同期は差損△41億)→経常の減少率(-24.2%)が営業(-39.4%)より小さい。円安は営業でマイナス・営業外でプラスの両建てで、ここを混同すると「経常はまだマシ」と誤読する
株価は発表翌日に対TOPIX-16.4ptと最も厳しい反応
横断スクリーニングの結論: 2026年の下方修正の主犯は円安ではなく中東情勢

Ⅶ. データセンター電力インフラ（重電4社）— 2028年が分水嶺

日立6501 / 三菱電機6503 / 富士電機6504 / 明電舎6508。DC投資は「サーバー(半導体)→建屋→受変電・電源」の順に発注が流れ、電力インフラは最も遅行かつリードタイムが長い。メモリ市況と切り離せる一方、判断軸はネットキャッシュではなく受注残の年数になる。

ただし「もう頭打ち」という有力な反証がある（最重要）

Rystad Energy(2026年5月末白書): 世界の変圧器製造能力は2025年に4,700GVA(約400工場)。2026年だけで約200GVA増設、2026〜28年が大増設の波。欧州50-100MVA案件の落札単価は$30,000〜35,000/MVAで横ばい。「供給制約はOEMの新規投資で緩和の兆し」「納期・価格ともstagnating(頭打ち)」「単価が現行水準を超えて上昇するとは見ていない」と明言。
さらにブローカー筋(POWER Magazine 2026/1/2併載)は「不足は存在しない。標準的な変電所用変圧器は図面承認後12〜14ヶ月で納入可能。価格を釣り上げるための誇張で、ボトルネックは工場能力ではなく電力会社/EPCの調達プロセス」と反論。
Wood Mackenzie/PwC/日立は「逼迫継続」、Rystadは「頭打ち」と2026年前半に評価が真っ向から割れており、「納期が今も延び続けている」という断定はできない
