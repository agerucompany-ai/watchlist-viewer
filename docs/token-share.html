⚠ この数字の読み方（必ず先に読む）
  • OpenRouter経由のトラフィックのみ。市場全体のごく一部にすぎず、大企業のクラウド直接契約・自社ホスト推論は一切含まれない。
  • 母集団はモデルを乗り換えやすい価格感応的な層（個人開発者・コーディングエージェント等）に強く偏る。エンタープライズの実態とは別物。
  • 収益は表示価格ベースの換算。実際の請求はキャッシュ割引・バッチ・年間契約で大きく下振れするため、金額の絶対値ではなく変化の方向を見ること。
  • キャッシュトークンは API が全モデル0を返す（未提供）ため、キャッシュ割引を反映できない。実際にはプロンプトキャッシュが効くモデルほど収益換算が過大に出る。
  • batch variantは50%引きを仮定して適用している（OpenRouterの一般則。個別モデルでの確証はないため、これは仮定であることを明示する）。
  • 履歴は自前蓄積。現在の完全な日次データは46日分で、毎日バッチを回すほど精度が上がる。
  • tools系列はtool-calling用途のサブセット＝別母集団。上の全体系列と混ぜて解釈しないこと。
