② アクティビスト・スリーブ — 保有理由と「彼らの出口戦略」

出口戦略はファンド側がこのポジションをどう回収するつもりかの分析(過去のエグジット実績からの類推)。われわれの売買ルールは④に別掲。

保有理由: SCが毎月+1%の機械的ペースで買い増し、EDINET変更報告書(2026/7/27)の重要提案行為等欄に「2026年8月末迄に、資本政策に関する重要な変更(有利子負債の活用及び株主資本の抑制)、重要な財産(有価証券及び賃貸等不動産)の処分及び増配」を原文明記。日付の読める唯一のカタリスト。

④ タイムラインと運用ルール（われわれ側の売買）

Phase 1（8/15〜8月末）: ニップンの提案発表を待つ。発表初動+10%超→半分利確(SCは数年持つが、われわれは初動だけ頂く)。大型提案(政策保有売却+大幅増配)なら残りは12月まで保有。8月末までに不発→9月第1週に全量撤退
Phase 2（9月〜12/30）: ニップンの回収資金はメタルアート・三菱製紙・ガンホーへ均等追加。大量保有の変更報告を週次監視——ファンドの買い増し=ホールド継続、保有割合の減少=彼らの出口が始まった合図なので追随売却(村上系は還元発表の翌日に売る髙島屋型に注意)。好決算スリーブは11月の次回決算で判定入れ替え
共通損切り: 全銘柄、取得値-12%で機械的に撤退

⑥ 前提とリスク

  • 市場前提: 日経66,000円台の高値圏。9銘柄すべてネットキャッシュ・資産バリュー系(CNPER0.4〜16)で、指数調整時のダウンサイドは市場平均より浅い想定
  • アクティビスト枠のリスク=時間: カタリストは「出ない」ことがある。ニップン以外は時期の保証なし。ファンドの変更報告(保有割合減少)は彼らの出口開始=われわれの撤退シグナル
  • 業績枠のリスク=モメンタム切れ: ☆判定は今回決算時点のもの。11月決算で前提が崩れた銘柄は機械的に入れ替える。ＡＲＥは金価格、電業社・日車輌は官公需/受注の期ズレでブレる
  • 流動性: メタルアート・電業社は出来高が薄く指値分散必須
  • 確率・目標はすべて推定。投資判断は自己責任で。基礎データ: CNPER分析 / 保有マップ / ウォッチリスト
