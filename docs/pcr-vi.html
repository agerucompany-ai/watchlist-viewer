指標判定根拠
日経 PCR÷VI 下位10%（買い増しゾーン）残す20日後 平常比+2.2%・60日後+6.1%／3期間とも同じ向き／ただしリスクも同量増える
売り・退避（PCR÷VI 上位25%）削除手仕舞うと年率12.8%→8.4%／米国36年では点灯中の急落率が平常の半分
打診買い削除平常比+0.8%・偶然と区別できない
強弱5段階（PCR+VI / SKEW+VIX）削除ストロング系は独立5〜7回で検証不能／VI高は2026年92%点灯で機能停止

米国 SKEW÷VIX削除VIXとほぼ同じ動き（順位相関0.96）・期間で向きが割れる

指標の見方
・PCR (全体OI) = フロント限月の全プット建玉 ÷ 全コール建玉。1.0以上で下落ヘッジ厚（弱気）、低位は強気・楽観。
 補助: PCR(OTM) = ATM±20%レンジ内のみ。
・日経VI = 投資家が想定する向こう30日の日経平均ボラ。20以下は穏やか、30超は警戒。
・PCR÷VI（スプレッド）= テールリスクと買い圧力を一体評価。
・買い増しゾーン = 当日の PCR÷VI が、当日を含まない直前750営業日（有効値）の下位10%を下回った日。有効値が250日たまるまでは判定しない。売りシグナルではない。
・市場指標 = USDJPY / VIX(米国) / TOPIX(1306) / 米10年金利 / S&P500 / SKEW（参考値）。
